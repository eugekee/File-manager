# File-manager
File_manager

Требуется Python 3.7+

git clone <repo_url>

Графический интерфейс для управления файлами с базовыми операциями.

Функции:

- Создание и удаление папок
- Поиск файлов по регулярному выражению
- Добавление даты к именам файлов
- Просмотр информации о файлах/папках
- Сортировка содержимого папки
- Создание текстового файла
